// security

What gets stored.

Kaskas follows PCI DSS data minimization principles.

Stored (safe)

  • Merchant names (e.g. Jollibee, Meralco)
  • Transaction amounts and dates
  • Last 4 digits of cards (****1234)
  • Last 4 digits of account numbers
  • Spending categories

Never stored

  • Full card numbers
  • CVV / security codes
  • Passwords or PINs
  • Full account numbers
  • Personal identification numbers
