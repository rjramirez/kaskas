## How to Maximize Promos

### Stack Strategy
1. Use credit card with category bonus
2. Pay via e-wallet for additional cashback
3. Apply voucher code
4. Use loyalty card for points
5. Shop during sale dates

### Example Stack
```
Purchase: PHP 1,000 at Shopee
- 11.11 Sale: 15% off = PHP 150
- Shopee Voucher: PHP 50 off
- ShopeePay: 5% coins = PHP 40
- Credit Card: 2% cashback = PHP 16
Total Savings: PHP 256 (25.6%)
```
